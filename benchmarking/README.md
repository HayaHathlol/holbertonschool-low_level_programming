# Green Tech Efficiency & Benchmarking Lab

## Description

This project focuses on measuring and analyzing the performance of C programs to understand software efficiency and its relationship to energy consumption.

## Learning Objectives

- Compile C programs using GCC with strict compiler flags.
- Measure execution time using `clock()` and `CLOCKS_PER_SEC`.
- Compare algorithm performance using benchmarking.
- Analyze execution time across different program phases.
- Understand the relationship between runtime and energy efficiency.
- Document measurements and conclusions in a technical report.

## Project Files

- `baseline_loop.c` - Measures execution time for a fixed number of iterations.
- `baseline_loop-metrics.md` - Records baseline execution results.
- `comparison_algorithms.c` - Compares Naive and Single-pass algorithms.
- `comparison_algorithms-metrics.md` - Records execution times and performance comparisons.
- `instrumentation_lab.c` - Measures execution time across multiple program phases.
- `green_efficiency_analysis.md` - Contains the final performance analysis and conclusions.

## Conclusion

This project demonstrates the importance of benchmarking, accurate performance measurement, and evidence-based reasoning when developing efficient and sustainable software.
